1. Unterscheidung: Keine Parallelisierung von Hotspots, sondern Restrukturierung anhand von Szenarien
2. Meta-Model, das effizient komplizierte und Datenbanbhängigkeitsanalysen auf beliebigen Teilen der Software ermöglicht
3. Visualisierungsframework, das skalierbare Abstraktionen und Interaktionen bietet für die Darstellung von Verhalten und Struktur von Software
4. Methode für SAR, welches benutzerdefinierte Abstraktionen ermöglicht. Die selben Abstraktionen wie die der Entwickler.
5. Evaluation anhand von einem kleinen Beispiel für das Verständnis und einem größeren Software mit 200.000k Zeilen Code.

3. Momentan ist Parceive beschränkt auf monolithisch Anwendungen -> Eine Erweiterung für verteilte Systeme Architekturen wäre Sinnvoll...
